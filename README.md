# Claude Code for umbrelOS (community app store)

Add this repo's URL under App Store -> ... -> Community App Stores, then install **Claude Code**.
Open it, run `claude`, sign in. Data lives in the app's `data/home` (persists across restarts).
LAN-only: the web terminal is shell access inside the container.

Also included: **Orca** (shuff57-orca), the stablyai/orca agent workspace in a browser-streamed XFCE desktop (webtop), with Claude Code preinstalled.
